iPhone 桌面安装与手表配合步骤

1. 添加到 iPhone 桌面

在 iPhone 自带 Safari 浏览器 打开部署后的 HTTPS 网址 → 点底部「分享」→「添加到主屏幕」，即可像原生 App 一样全屏打开。

2. Apple Watch 快捷录音

把手表自带「语音备忘录」放到表盘复杂功能或操作按钮上，抬腕即可开录；录完自动通过 iCloud 同步到 iPhone。

3. 填入 API Key 开始分析

点右上角齿轮图标填入 Gemini API Key（免费额度即可用，且直接支持 `.m4a` 音频）或 OpenAI 兼容 Key。
