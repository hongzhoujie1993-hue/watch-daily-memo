iPhone 桌面安装与心率压力自动同步

1. 添加到 iPhone 桌面

在 iPhone 自带 Safari 浏览器 打开部署后的 HTTPS 网址 → 点底部「分享」→「添加到主屏幕」，即可像原生 App 一样全屏打开。

2. 自动读取 Apple Watch 心率与压力（HRV）

由于浏览器隐私限制无法直接读取 Apple Health，你可以在 iPhone「快捷指令」新建一个指令：读取「健康」最新心率和心率变异性 (HRV)，然后打开链接：https://你的域名/?hr=心率&hrv=HRV，打开本应用时会自动填入当时心率并换算实时压力！

3. 填入 API Key 开始分析

点右上角齿轮图标填入 Gemini API Key（直接支持 `.m4a` 音频）或 OpenAI 兼容 Key，AI 会结合心率波动与对方原话给出深度心情与潜台词分析。Key 只存在你自己手机的浏览器里，不会上传到任何服务器。

4. 手表上怎么录（实话）

网页版装不到手表上当原生 App。手表上的走法是：用手表自带的「语音备忘录」点一下录，录完在 iPhone 上分享到「文件」，再回到这里导入；或者直接在 iPhone 上点「应用内直接录音」。录音只保存在你自己手机里，刷新、关掉再打开也不会丢（v3 已修）。

另外提醒一句：录别人说话前先跟对方打个招呼，只拿来做自己的复盘，别外传。
